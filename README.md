The Lunar Surface: Elevation & Relief Mapping

Project Overview

A high-resolution cartographic visualization of the Moon's surface, illustrating its elevation distribution and relief features in an Equidistant Cylindrical Projection. This map highlights the dramatic contrast between smooth, low-lying lunar maria (basaltic plains) and rugged, heavily cratered highlands across 50°N to 50°S and 150°W to 150°E, with elevation values ranging from 10,421.5 to -8,556.

Data Acquisition

The 118m resolution Lunar Digital Elevation Model (DEM) raster dataset was acquired from the NASA / USGS Astrogeology Science Center (Astropedia Lunar and Planetary Catalog).

Methodology & Workflow

The raw 118m lunar elevation dataset was imported, processed, and reprojected into an Equidistant Cylindrical coordinate system using QGIS. A multi-directional hillshade layer was generated to emphasize terrain depth, crater rims, and surface textures, which was then blended with a custom hypsometric color ramp. Finally, geographic graticules, a scale bar, and an elevation legend were designed in the QGIS Print Layout for accurate spatial representation.
